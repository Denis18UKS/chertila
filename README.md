# Chertila

Desktop-программа на Python с интерфейсом pywebview для генерации чертежей варианта 14 по приложенным схемам и передачи геометрии в КОМПАС-3D через COM API.

## Что умеет

- показывает предпросмотр трёх схем варианта 14 в HTML-интерфейсе pywebview;
- строит 1-й и 2-й чертёж в горизонтальной ориентации;
- строит 3-й чертёж в вертикальной ориентации;
- сохраняет результат в SVG для быстрой проверки;
- сохраняет DXF как резервный формат;
- отправляет геометрию в КОМПАС-3D через `KOMPAS.Application.5` при запуске на Windows с установленным КОМПАС-3D и `pywin32`.

## Запуск

```bash
python -m chertila
```

Установите зависимости для pywebview. На Windows этот же файл подтянет `pywin32` для прямого экспорта в КОМПАС-3D:

```bash
python -m pip install -r requirements.txt
```

## Работа с программой

1. Выберите одну из схем в списке.
2. При необходимости прикрепите скриншот-референс, чтобы зафиксировать исходную картинку в интерфейсе.
3. Нажмите **Экспорт SVG** или **Экспорт DXF** для сохранения файла.
4. Нажмите **Построить в КОМПАС-3D**, если программа запущена на Windows и КОМПАС-3D доступен через COM.

## Структура

- `chertila/app.py` — pywebview-интерфейс desktop-приложения и JavaScript API-мост.
- `chertila/variants.py` — параметрические схемы варианта 14.
- `chertila/exporters.py` — SVG/DXF-экспорт и COM-интеграция КОМПАС-3D.
- `chertila/model.py` — простая модель чертёжных примитивов.
- `tests/` — тесты генерации схем и файлов экспорта.
